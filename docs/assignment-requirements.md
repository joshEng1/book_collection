# Assignment requirements

Source: the four Book Collection assignment documents supplied with this task.
GitHub Classroom instructions do not apply. Use `dev` → PR → `test` → PR → `main`.
The user requested plain functional views; custom CSS is unnecessary.

## Book Collection 1

- Rails and PostgreSQL; migrations; MVC; resourceful routes.
- Book title, index, add, show, edit, and a separate delete confirmation page.
- Successful mutations show a flash on the home page. Every page links home.
- Evidence: five pages, flash, running localhost application, approved PR before
  merge, commit history, and an AI rubric analysis with improvement suggestions.

## Book Collection 2

- RSpec unit and integration tests, including valid and blank titles.
- Write tests before adding author, decimal price, and published date.
- Capture initial failures, intermediate mixed results, and the passing suite.
- Published date uses dropdowns.
- Evidence: test stages, approved PR, commit history, and AI rubric analysis.

## Book Collection 3

- Heroku or an instructor-approved deployment platform.
- Review, staging, and production deployment; exercise CRUD in each environment.
- Supply environment URLs, pipeline screenshot, and user stories with acceptance
  criteria that an instructor can use for testing.

## Book Collection 4

- User has a username. UserBook joins users and books in a many-to-many relationship.
- CRUD for users and user books; select existing users and books using dropdowns.
- Root route displays User Books, with links to books, users, and new user book.
- Evidence: users page, association form, home page, routes, approved PR, commit
  history, and AI rubric analysis.

## Submission

- Four PDF reports with numbered, explained screenshots and repository links.
- One cumulative reflection, at most two pages: tools, substantial application
  changes, a test/defect and fix, a checked or rejected AI suggestion, and customer readiness.
- Capture actual results only. Never invent approvals, deployment URLs, test
  history, or personal experience. Reflection requires the student's review.
- Exclude credentials and personal information from submission contents.
